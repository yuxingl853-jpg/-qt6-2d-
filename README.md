# -qt6-2d-
2d酷跑 (TianTian KuPao) - Qt6 跑酷小游戏
欢迎来到 天天酷跑！这是一个基于 Qt6 框架开发的 2D 横版跑酷小游戏。玩家通过键盘控制角色在无尽赛道上奔跑，躲避障碍物、收集金币，挑战自己的反应极限与最高分。
游戏特色
经典跑酷玩法：流畅的跳跃与滑行机制，体验速度与激情。
动态难度递增：随着奔跑距离的增加，障碍物密度与移动速度会动态提升。
丰富道具系统：收集金币与特殊道具（），获取高分与特殊能力。
跨平台支持：基于 Qt6 构建，支持 Windows、macOS、Linux 等多平台运行。
本地数据存档：自动记录历史最高分，随时挑战自我。
在开始之前，请确保您的开发环境满足以下条件：
C++ 编译器（支持 C++17 及以上标准，如 MSVC, GCC, Clang）
CMake (版本 >= 3.16)
Qt 6.x 完整开发环境 (包含 Qt Quick / Widgets 模块)
Qt Creator (推荐) 或您喜欢的 IDE
